¿Qué es GreenSpark?

Una plataforma de simulación avanzada que ayuda a universidades, colegios y empresas a investigar la generación de electricidad a partir de materia orgánica antes de invertir en infraestructura física.

El foco del proyecto está en las Celdas de Combustible Microbianas (MFC): reactores bio-electroquímicos que aprovechan el metabolismo de bacterias anaeróbicas para oxidar materia orgánica y generar electrones libres, produciendo una corriente eléctrica directa.

Priorización Científica

Funcionamiento de una Celda MFC
La materia orgánica se oxida en el ánodo liberando electrones (energía) y protones (que cruzan la membrana).

El Problema de los Residuos

Una enorme cantidad de energía potencial se desperdicia diariamente por la falta de viabilidad y datos locales.

De residuos orgánicos al día

Es la alarmante cantidad generada en la ciudad de Santa Cruz de la Sierra, Bolivia.

El obstáculo de la incertidumbre

La mayor parte de los residuos biológicos termina en vertederos (como el de Normandía o San Miguel de los Junos) sin ningún tipo de aprovechamiento energético. Las instituciones, industrias y universidades interesadas en la sostenibilidad ambiental enfrentan barreras críticas:

  • Falta de datos locales: No se sabe con certeza qué residuos nativos (cáscaras de frutas, restos de comida, lodos) son óptimos para generar electricidad.
  • Inversión de alto riesgo: Implementar reactores físicos sin saber su producción eléctrica estimada es económicamente inviable.
  • Complejidad bioquímica: Variables críticas como la temperatura, el pH, la humedad y el tipo de inóculo bacteriano interactúan de forma no lineal, haciendo difícil la predicción manual.

Trazabilidad y Calidad de Datos

Cada resultado en la plataforma se etiqueta explícitamente para evitar alucinaciones y asegurar rigor científico:

SIMULADO

Datos inferidos mediante modelos de Machine Learning (Random Forest, Gradient Boosting). Tienen un margen de error estadístico reportado por el sistema.

MEDIDO

Resultados procedentes de validaciones físicas previas en laboratorio o de sensores en tiempo real de celdas activas.

META EXPLORATORIA

Modelos y estimaciones a largo plazo para evaluar el escalamiento industrial potencial a partir del volumen de residuos analizados.

Stack Tecnológico

Herramientas y tecnologías modernas para garantizar estabilidad, escalabilidad y precisión científica.

💻

Frontend

  • React 18 + TS: Interfaz ágil e interactiva que valida parámetros en el cliente.
  • Vite: Compilador ultra-rápido para un desarrollo óptimo.
  • React Router v6: Gestión fluida de navegación en la consola del simulador.
⚙️

Backend & DB

  • FastAPI (Python): Backend de alto rendimiento con validación automática vía Pydantic.
  • SQLite: Base de datos ligera e integrada, ideal para pilotos y hackatones.
  • SQLAlchemy: Mapeo ORM para gestionar la persistencia y trazabilidad de escenarios.
🧠

Datos, ML & IA

  • pandas & scikit-learn: Análisis de datos y modelos predictivos (Random Forest, Gradient Boosting).
  • LLM API (Opcional): Generación semántica de reportes en lenguaje natural para toma de decisiones.
